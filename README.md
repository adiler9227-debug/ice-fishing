# Ледяная рыбалка 🎣

Браузерная игра. Прогресс каждого игрока хранится на сервере. Аккаунты не нужны: игроку выдаётся код из 6 знаков (виден в меню ⚙️). По этому коду можно продолжить игру на другом телефоне.

Игра живёт отдельно от других игр на сервере:

| | Ледяная рыбалка |
|---|---|
| Папка | `/opt/ice-fishing` |
| Служба | `fishing` |
| Порт | 3001 (или первый свободный после него) |
| Сохранения | `/var/lib/ice-fishing` |
| Копии сохранений | `/var/backups/ice-fishing` (каждый день, 14 дней) |

## Установка (один раз)

1. Создай репозиторий `ice-fishing` на GitHub и загрузи в него все файлы из этого архива.
2. Зайди на сервер (Termius) и выполни (вместо `ИМЯ` подставь свой логин GitHub):

```
git clone https://github.com/ИМЯ/ice-fishing /opt/ice-fishing && bash /opt/ice-fishing/install.sh
```

В конце появится ссылка вида `http://АДРЕС:3001`. Её и открывать на телефоне.

Если ссылка не открывается: в Hetzner Console → Firewalls (если файрвол включён) добавь входящее правило TCP на этот порт.

## Обновление

```
bash /opt/ice-fishing/update.sh
```

## Полезное

- Состояние: `systemctl status fishing`
- Журнал: `journalctl -u fishing -n 50`
- Сколько игроков: `ls /var/lib/ice-fishing/players | grep -c -v bak`
